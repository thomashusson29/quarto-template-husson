L'adaptateur Husson (`pptx/export.mjs`, `pptx/post-render.mjs`) et son interface (`gui/app.py`) sont du code original écrit pour ce template. La pagination automatique et l'export des onglets suivent la structure HTML décrite par la [documentation RevealJS de Quarto](https://quarto.org/docs/presentations/revealjs/) ; aucun code Quarto n'est copié. Il applique la modification du bundle `dom-to-pptx` décrite ci-dessus uniquement pendant l'exécution et ne copie pas les projets seulement consultés. Pour les caractères CSS générés, `pptx/export.mjs` utilise le protocole DevTools de Chromium via Puppeteer pour vérifier la couverture des glyphes et choisit la première police couvrant réellement le caractère dans l'ordre Carlito, Open Sans, Arial ; ces caractères restent des objets texte. Il augmente aussi l'interligne PowerPoint d'un paragraphe lorsque celui-ci est inférieur à la taille de son plus grand texte inline. L'option `autoEmbedFonts: true` de `dom-to-pptx` intègre les quatre variantes Carlito dans le PPTX à partir des déclarations `@font-face` locales.
