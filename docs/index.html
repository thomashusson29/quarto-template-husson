Quarto Template Husson

Extension de publication scientifique multi-format pour Quarto

Version 1.3.0 Quarto >= 1.8 XeLaTeX / Typographie Auto Dark One Dark Pro

Utilisation Rapide

# Créer un nouveau projet prêt à l'emploi

quarto use template thomashusson29/quarto-template-husson mon-projet

# Ajouter l'extension à un projet Quarto existant

quarto add thomashusson29/quarto-template-husson

# Lancer la compilation des formats

quarto render mon-document.qmd --to husson-html quarto render mon-document.qmd --to husson-revealjs quarto render mon-document.qmd --to husson-pdf quarto render mon-document.qmd --to husson-docx
